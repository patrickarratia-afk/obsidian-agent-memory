# Context Capsules — StockCheck

## Rules

- **Target ≤ 60 lines, hard max 80 lines.**
- **FACT-only.** No inferences, speculation, or AI-generated summaries posing as facts.
- **reviewed: false** for AI-created capsules until a human checks them.
- **Do not copy Project Wiki content.** Reference canonical Project Wiki pages/paths for deeper context.
- Capsules contain only the minimum facts needed to resume work.

## Lifecycle

1. Create when a new domain boundary becomes stable (passes 3-evidence gate).
2. Update only when a FACT is verified incorrect or a new high-value boundary is established.
3. Remove when the domain is no longer active — archive the capsule, do not delete.
